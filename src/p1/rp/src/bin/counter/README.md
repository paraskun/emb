# Счетчик

> [!WARNING]
> Проект выполнялся в учебных целях, поэтому все описанное далее настоятельно рекомендуется подвергнуть критике, опираясь на более авторитетные источники.

Микроконтроллер RP2040 оснащен уникальной интегральной подсистемой - PIO. Подробнее о том, что это такое и зачем нужно можно посмотреть [тут](https://pip-assets.raspberrypi.com/categories/814-rp2040/documents/RP-008371-DS-1-rp2040-datasheet.pdf) и [тут](https://rp2040.implrust.com/pio/index.html).

Алгоритм ниже можно оптимизировать как минимум тремя способами. Один из них (самый эффективный) - с привлечением дополнительной схемы.

```asm
.side_set 2
.wrap_target
    ; Эта и следующая инструкции выполняют следующее: если CPU отправил
    ; нам новую информацию (цифры), то мы складываем их в X, а если нет,
    ; то оставляем X как есть и идем дальше.
    pull noblock        side 0b00 [1]
    mov x, osr          side 0b00 [1]

    ; Блоки ниже - идентичные, за исключением подсвеченного разряда.

    ; Чтобы не было остаточного эффекта (на одной цифре немного просвечивает другая),
    ; мы выключаем все цифры перед тем, как дернуть latch.
    set pins, 0b1111    side 0b00 [1]
    set y, 7            side 0b00 [1]
loop1:
    out pins, 1         side 0b00 [1]
    nop                 side 0b01 [1] ; clock
    jmp y-- loop1       side 0b00 [1]
    nop                 side 0b10 [1] ; latch
    set pins, 0b0111    side 0b00 [3]

    ; ---

    set pins, 0b1111    side 0b00 [1]
    set y, 7            side 0b00 [1]
loop2:
    out pins, 1         side 0b00 [1]
    nop                 side 0b01 [1] ; clock
    jmp y-- loop2       side 0b00 [1]
    nop                 side 0b10 [1] ; latch
    set pins, 0b1011    side 0b00 [3]

    ; ---

    set pins, 0b1111    side 0b00 [1]
    set y, 7            side 0b00 [1]
loop3:
    out pins, 1         side 0b00 [1]
    nop                 side 0b01 [1] ; clock
    jmp y-- loop3       side 0b00 [1]
    nop                 side 0b10 [1] ; latch
    set pins, 0b1101    side 0b00 [3]

    ; ---

    set pins, 0b1111    side 0b00 [1]
    set y, 7            side 0b00 [1]
loop4:
    out pins, 1         side 0b00 [1]
    nop                 side 0b01 [1] ; clock
    jmp y-- loop4       side 0b00 [1]
    nop                 side 0b10 [1] ; latch
    ; Тут ждать доп. 2 такта не надо, т.к. далее мы потратим два такта
    ; на проверку данных от CPU. Если тут поставить 3, то каждую итерацию
    ; первая цифра будет гореть дольше, а значит будет ярче.
    set pins, 0b1110    side 0b00 [1]
.wrap
```

Директива `.wrap` - бесплатный `jmp`. Как видно, для инструкции `jmp` требуется один такт. Для `wrap` он не нужен и мы можем обернуть в него весь алгоритм.
